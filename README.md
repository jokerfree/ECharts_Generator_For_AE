# AE 可编辑图表生成器 — 功能与使用说明

> **版本**：v5.2　**文件**：`echarts_generator.jsx`（约 2760 行）
> **参考**：ECharts 官方配置项（https://echarts.apache.org/zh/option.html）
> **形态**：AE ExtendScript（`.jsx`）+ ScriptUI 面板；生成的图层 **全部可编辑**

---

## 一、快速上手

### 1.1 安装与运行

1. 打开 After Effects（建议 CC 2018 及以上）。
2. `文件 → 脚本 → 运行脚本文件…`，选择 `echarts_generator.jsx`。
   - 想做成常驻面板：把文件放到 `Support Files/Scripts/ScriptUI Panels/`，重启 AE 后在 `窗口` 菜单底部找到它。
3. 面板打开后即可配置 → 点底部 **「生成图表」**。

### 1.2 生成的产物

- 自动新建（或复用）一个 **1920×1080 / 30fps** 的合成，名字取自主标题（主标题为空时叫「图表合成」）。
- 所有图层带注释标记 `AE_CHART_AUTO`。**再次点「生成图表」会先清掉上次自动生成的图层再重建**——所以反复调整参数不会堆叠垃圾，但也意味着你在这些图层上的手工改动会被冲掉。
- 合成时长会自动按 `动画时长 + 错落 × 3 + 1.2 秒` 延长，保证动画播完。

| 标题 | 显示标题 | 勾选 | 关掉后不画标题，合成名回退为「图表合成」 |
| | 主标题 / 副标题 | `基础柱状图` / 空 | 合成名取自**主标题**（非法字符会被替换为 `_`） |
| | 主标题色 / 副标题色 | `#FFFFFF` / `#BBBBBB` | 带取色按钮 |

**数据格式要点**

- 数值与标签用**英文逗号**分隔，多余空格会被忽略。

- 各系列数值个数不一致时，短的那条后续位置按 0 处理。
- 正负值柱 / 瀑布图**只用系列 1 的数据**，但仍需保证逗号分隔格式正确。

| 参数 | 默认 | 说明 |
|---|---|---|
| 柱宽 | `35%` | 支持百分比（相对单槽宽）或像素 |
| 最大宽度 | 0 | 0 = 不限制；否则取 `min(柱宽, 最大宽度)` |

## 四、进阶类型的输入与期望输出

### 4.1 正负值柱状图

**输入数据**（「数据」页 → 系列1 数值）

```
120,-60,90,-140,70
```

**期望形态**

- 画布中有一条 **0 轴基准线**。
- `120 / 90 / 70` 三根从 0 轴**向上**长；`-60 / -140` 两根从 0 轴**向下**长。
- Y 轴自动定为 **-150 ~ +150**（按绝对值最大项 140 向上取整刻度）。
- 所有柱子都在绘图区内，没有一根冲出边界。

**期望几何**（1920×1080 合成，绘图区 y 180~920，0 轴在 y=550）

| 图层 | 方向 | 高度(px) | 实际占用区间 y |
|---|---|---|---|
| 柱_0 | ↑ 正 | 296.0 | 254 → 550 |
| 柱_1 | ↓ 负 | 148.0 | 550 → 698 |
| 柱_2 | ↑ 正 | 222.0 | 328 → 550 |
| 柱_3 | ↓ 负 | 345.3 | 550 → 895 |
| 柱_4 | ↑ 正 | 172.7 | 377 → 550 |

> 判据：正值柱区间是 `[x, 550]`，负值柱区间是 `[550, y]`。

### 4.2 瀑布图

**输入数据 —— 注意填的是**增量**，可为负**

```
60,-25,40,-15,30
```

**期望形态**（对齐 ECharts 官网示例）

| 类别 | 增量 | 累计 |
|---|---|---|
| A | 60 | 60 |
| B | -25 | 35 |
| C | 40 | 75 |
| D | -15 | 60 |
| E | 30 | 90 |

- **只有 5 根柱，没有「合计柱」。**
- 每根是**悬浮段**，代表这一步的增量：A 从 0 长到 60（蓝，增）、B 从 60 缩到 35（红，减）、C 从 35 长到 75、D 从 75 缩到 60、E 从 60 长到 90。
- 相邻柱之间有**水平虚线**，连在前一段的终点高度上。
- Y 轴按**累计和的极值**定为 0 ~ 90。

> **常见误区**：往数据里塞一堆正数以为会"累计成柱状"。瀑布图每根柱画的是**这一步的变化**，不是累计值。

### 4.3 堆叠类

- **堆叠柱状图 / 堆叠面积图 / 堆叠折线图 / 水平堆叠条形图**：Y 轴按**各分类的累计和**定上限（不是按单系列最大值）。多系列数据累加后不会冲出绘图区。
- **堆叠百分比柱状图**：各分类归一化到 100%，Y 轴固定 0~100。标签可切「百分比 / 原始数值」。

### 4.4 双Y轴组合图

- 系列 1 走左轴（按系列 1 的 min/max 定轴），系列 2 走右轴。
- 右轴的数值后缀用「坐标轴」页的 **右轴后缀** 单独设置，可以做出「左侧金额(万) / 右侧增长率(%)」这类效果。

## 五、Y 轴范围是怎么算的（重要）

不用手填，脚本按类型分支自动计算：

| 类型 | 定轴依据 |
|---|---|
| 基础/分组/水平/饼图外的普通类型 | 所有系列的 min / max |
| **堆叠柱 / 堆叠面积 / 堆叠折线 / 水平堆叠** | **各分类累计和**的 min / max |
| 堆叠百分比 | 固定 0 ~ 100 |
| 双Y轴组合图 | 系列 1 的 min / max |
| 柱状+折线组合 | 所有系列的 min / max |
| **正负值柱状图** | 所有系列的 min / max |
| **瀑布图** | **累计过程中的极值**（若最大累计为负则上限归 0） |

当 `min < 0` 时自动改用 `calculateTicksSigned`（正负双向刻度），否则用 `calculateTicks`（单向刻度）。
